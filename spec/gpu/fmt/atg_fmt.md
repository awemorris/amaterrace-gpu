# atg_fmt (format functions)

RTL: `include/atg_fmt_info.vh`, `include/atg_fmt_unpack.vh`, `include/atg_fmt_pack.vh` and the generated `include/atg_srgb.vh` (functions, included inside a module).  Users: atg_vf_conv (unpack), atg_tu_ffilt (unpack), atg_rop_wpix and atg_rop_fblend (unpack of the destination, pack), atg_cp_fmt (the feature table), atg_blt (resolve).  Lint: the lint-only top `sim/lint/atg_fmt_lint.v`.

## 1. Purpose and place

One table of the formats the GPU has, by VkFormat value, and the conversions between a texel or pixel of any of them and four 32-bit components, shared by the vertex fetcher, the texture unit, the render output and the blitter, so that what the units do and what the FMT capability reports (atg_cp_fmt) come from the same table.

## 2. Parameters

None.  The include order is `atg_srgb.vh`, `atg_fmt_info.vh`, then `atg_fmt_unpack.vh` and/or `atg_fmt_pack.vh`.  `atg_fmt_info.vh` declares the localparams `ATG_FMT_UNORM` .. `ATG_FMT_E5` (the type codes); function locals have the prefixes `fi_`, `fu_` and `fp_` so they do not hide a module's signals.

## 4. Behaviour

- **unpack**: a component is the field at its position and width.  UNORM c / (2^b - 1), b = 1, 2, 4, 5, 6, 8, 10, 16 or 24, to the nearest fp32 (c / (2^b - 1) is 0.ccc... in binary: the leading 72 bits of c repeated give the fp32 and its rounding bits, and the result is never a tie).  SNORM max(c / (2^(b-1) - 1), -1), b = 8 or 16, likewise (the most negative code is -1.0).  UINT zero extended, SINT sign extended to 32 bits.  SFLOAT 32 bits as they are, 16 bits exactly (denormals to normal fp32, infinities kept, NaN 0x7FC00000).  UFLOAT 11 and 10 bits (5 exponent bits, bias 15) and E5B9G9R9 (m x 2^(E - 24)) exactly, NaN 0x7FC00000.  sRGB: R, G, B through `atg_srgb_dec`, A as UNORM.  Components the format does not have read 0, 0, 0 and 1.0 (integer formats: integer 1); is_int is 1 for UINT and SINT.  Depth formats give the depth in c0 (D16 and D24 as UNORM, D32_SFLOAT as it is).  stencil = 1: the stencil of D24_UNORM_S8_UINT as an integer (s, 0, 0, 1) with is_int 1; another format reads (0, 0, 0, 1.0).  A value without an entry, and a compressed format, read (0, 0, 0, 1.0).
- **pack**: only formats with the colour-attachment feature; any other writes nothing (keep all ones).  For each component c < components with wm[c]: UNORM RNE(clamp01(f) x (2^b - 1)), NaN and negative values (-0 included) 0, b <= 16; sRGB: R, G, B are 8-bit codes in [7:0] (the caller encodes them with atg_fmt_srgbenc), A is UNORM 8; SFLOAT 16 bits to nearest even (overflow to infinity, NaN 0x7E00, half denormals exact, fp32 denormals 0), 32 bits as they are; UINT and SINT the low b bits.  raw holds the written fields, keep a 1 for each bit of a masked component and every bit outside the pixel.
- The functions are combinational; each is a large case (the cost is in §6).

## 5. State machine

None (functions).

## 6. Latency and throughput

Combinational.  Size per call site, estimated (not synthesised): unpack ≈0.6-1.0k LUT, pack ≈0.5k LUT; a block that needs them at clock rate registers around them.

## 7. Corner cases and errors

- Format values without an entry are "no format" in every function (§4).
- `atg_fmt_unorm` with c = 0 is 0 and with c = 2^b - 1 exactly 1.0; widths not listed read as 24.
- 12-byte formats (R32G32B32) are vertex formats only: no sampled or colour feature.
- NaN inputs to pack: UNORM 0, half 0x7E00, 32-bit floats and integers keep their bits.

## 8. What the TB checks

`sim/tb/atg_fmt_tb.v` (vectors from `python3 -I tools/fmtmodel.py --vectors`) prints, in this order:

- `PASS atg_fmt.info` — atg_fmt_info and atg_fmt_feat (with and without the decoder) for all 256 values against the model
- `PASS atg_fmt.unpack` — every format and three values without an entry, the stencil aspect, every code of the single-component 1- to 11-bit formats, random texels, float specials
- `PASS atg_fmt.pack` — every format with random components and write masks; every UNORM code of 5, 6, 8 and 10 bits from its fp32 and the fp32 on each side
- `PASS atg_fmt.required` — the feature table has every fixed-function bit that Vulkan 1.0 requires (`tools/vk-required-formats.txt`, the specification's tables, independent of the model) and each "one of" group (X8_D24 or D32F depth/stencil, D24S8 or D32F_S8, one compressed family)
- `PASS atg_fmt` at the end.

`python3 -I tools/fmtmodel.py --selftest` prints `PASS fmtmodel.selftest`: the model's exact conversions against fractions, every fp16 both ways against Python's `struct` 'e', the 11- and 10-bit floats and E5B9G9R9, the D24 round trip c -> fp32 -> RNE(f x (2^24 - 1)) for every code, the sRGB tables against the definition at and beside every threshold, and the feature table against the required one.  `python3 -I tools/srgb-tables.py --check` prints `PASS srgb-tables.check`.
