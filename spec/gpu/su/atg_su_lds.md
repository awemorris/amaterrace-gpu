# atg_su_lds

RTL: `rtl/gpu/su/atg_su_lds.v`.  Parent: atg_su.  Implemented in: p008.

## 1. Purpose and place

Shared memory (LDS): lds/sts per lane, LDS_BYTES of block RAM per SU (4 KiB ZYBO, 16 KiB KC705), word addressed; returns as long beats.

## 2. Parameters

| Name | Default | Meaning |
| --- | --- | --- |
| `NPHYS` | `8` | Physical lanes: 8, 16 or 32 (a warp is 32 lanes, one instruction takes 32/NPHYS cycles). |
| `NWARPS` | `4` | Resident warps (slots): 2, 4 or 8. |
| `WARP_W` | `2` | log2(NWARPS). |
| `GRP_W` | `2` | log2(32/NPHYS): the lane-group number of a warp (0 for NPHYS 32 is given as 1 bit). |
| `SBE_W` | `2` | log2(SB_ENTRIES); the value of all ones above the entries is "no entry" (an entry index is SBE_W+1 bits). |
| `UOP_W` | `104` | Width of the decoded instruction (= ATG_UOP_W of include/atg_su_uop.vh). |
| `LDS_BYTES` | `4096` | Size in bytes. |

## 4. Behaviour

Per group, NPHYS lanes access the RAM in 32/NPHYS... in v1 one lane per cycle (a bank per physical lane is a later optimisation); lds returns one beat per group; sts completes with a beat without data.  Addresses wrap at LDS_BYTES.

## 5. State machine

IDLE → ACCESS (lanes) → RETURN → IDLE.

## 6. Latency and throughput

Latency 2 per access (design §3.4.2); one lane per cycle in v1.

## 7. Corner cases and errors

- Workgroup isolation: the scheduler allots LDS by workgroup (LDS_BYTES in STATE); v1 has one workgroup at a time per SU.

## 8. What the TB checks

`sim/tb/atg_su_lds_tb.v` prints, in this order:

- `PASS atg_su_lds.rw` — sts then lds of random lanes
- `PASS atg_su_lds.mask` — lanes outside the side-effect mask do not write
- `PASS atg_su_lds` at the end.
