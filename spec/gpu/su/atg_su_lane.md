# atg_su_lane

RTL: `rtl/gpu/su/atg_su_lane.v`.  Parent: atg_su.  Implemented in: p009.

## 1. Purpose and place

Cross-lane operations: qd (quad differences and swaps for derivatives, design §3.4.1) always; shfl/vote/ballot with SUBGROUP (staging RAM).  Short results.

## 2. Parameters

| Name | Default | Meaning |
| --- | --- | --- |
| `NPHYS` | `8` | Physical lanes: 8, 16 or 32 (a warp is 32 lanes, one instruction takes 32/NPHYS cycles). |
| `NWARPS` | `4` | Resident warps (slots): 2, 4 or 8. |
| `WARP_W` | `2` | log2(NWARPS). |
| `GRP_W` | `2` | log2(32/NPHYS): the lane-group number of a warp (0 for NPHYS 32 is given as 1 bit). |
| `SBE_W` | `2` | log2(SB_ENTRIES); the value of all ones above the entries is "no entry" (an entry index is SBE_W+1 bits). |
| `UOP_W` | `104` | Width of the decoded instruction (= ATG_UOP_W of include/atg_su_uop.vh). |
| `SUBGROUP` | `0` | shfl/vote/ballot present. |
| `SHORT_LAT` | `6` | Cycles from x_valid to the short result (one fixed pipeline for classes a and f, design §3.1.1). |

## 4. Behaviour

qd works inside a lane group (quads never cross groups since NPHYS ≥ 8).  shfl/vote/ballot need all 32 lanes: the unit stages the instruction's groups, then produces the results group by group (2 passes, design §3.4.2); x_ready is 0 meanwhile.

## 5. State machine

IDLE → (qd: PASS) | (shfl/vote/ballot: STAGE → EMIT) → IDLE.

## 6. Latency and throughput

qd one group per cycle; shfl 2 × 32/NPHYS cycles.

## 7. Corner cases and errors

None beyond the above.

## 8. What the TB checks

`sim/tb/atg_su_lane_tb.v` prints, in this order:

- `PASS atg_su_lane.qd` — qdx/qdy/qswap* against the model
- `PASS atg_su_lane.sub` — shfl modes, vote, ballot (SUBGROUP = 1)
- `PASS atg_su_lane` at the end.
