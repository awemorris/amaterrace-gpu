# atg_kc705_pcie

RTL: `boards/kc705/lib/atg_kc705_pcie.v`.  Parent: atg_kc705_raster.  Written in WS288 p013 (2026-10-25).

## 1. Purpose and place

The KC705's PCIe endpoint (docs/ghci.md §15.2): the Xilinx AXI Memory Mapped To PCI Express bridge (axi_pcie 2.9; the user's decision of 2026-10-25: an AXI bridge, XDMA's AXI Bridge mode is not offered for the 7 series in Vivado 2026.1) and the AXI cores around it, all generated by `boards/kc705/ip.tcl`.  Gen2 x4, 128-bit AXI at axi_aclk_out (125 MHz, user_clk).

## 2. Parameters

None.

13 ports and 3 AXI groups.

## 4. Behaviour

The bridge's BAR0 maps to AXI 0x0000_0000 and BAR2 to 0x8000_0000; a crossbar splits them (DECERR elsewhere) and a width converter gives BAR0 32-bit beats.  BARs are 32-bit (the bridge has one BAR width for all and no prefetchable choice; §15.2 asks BAR2 64-bit prefetchable: recorded deviation).  Class 03 80 00, vendor 10EE, device 7024.  MSI: one request at a time (vector 0 first), INTX_MSI_Request held until INTX_MSI_Grant, MSI_Vector_Num v when the host granted 2 vectors (MSI_Vector_Width > 0), else 0 for both; only while MSI_enable.  The bridge's control slave is unused.

## 5. State machine

The MSI request: idle → requesting (until the grant) → one idle cycle.
