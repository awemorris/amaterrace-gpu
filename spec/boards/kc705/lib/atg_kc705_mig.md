# atg_kc705_mig

RTL: `boards/kc705/lib/atg_kc705_mig.v`.  Parent: atg_kc705_top.  Implemented in: p012.

## 1. Purpose and place

The KC705 memory: MIG 7 Series DDR3 (1 GB, 64 bit, AXI4 512 bit, ui_clk 200 MHz, regenerated by TCL, design §4.1) behind two AXI4 slaves: `s_*` in gclk (atg_top's m_*) and `s2_*` in s2_clk (the PCIe BAR2 window, 128 bit; p013: the host's window does not go through the MC, so the aperture, quiesce and the CP's RESET do not touch it).  Inside (cores of `boards/kc705/ip.tcl`): BAR2 through an AXI clock converter (s2_clk → gclk) and a width converter (128 → 512), a crossbar of the two in gclk, the AXI clock converter to ui_clk.  The MIG takes address bits 29:0: atg_top's LOCAL_BASE + offset and BAR2's offset are the same byte.

## 4. Behaviour

The IP cores are generated by `boards/kc705/ip.tcl` (not committed; synthesised out of context, read by `tools/vivado-build.tcl` through `VIVADO_IP`): `atg_kc705_bar2_cc`, `atg_kc705_bar2_up`, `atg_kc705_mem_xbar`, `atg_kc705_axi_cc` (AXI Clock Converter, AXI4, ID 1, address 32, data 512, asynchronous: gclk → ui_clk) and `atg_kc705_ddr3` (MIG 7 Series 4.2 from `boards/kc705/atg_kc705_ddr3.prj`, the board file's DDR3 preset with AXI4 data 512, address 30, ID 4; system clock "No Buffer" from sys_clk (no BUFG in front of the MIG's PLL: with a BUFG the calibration failed on the board, the suspected cause, ws288 p024), reference clock "No Buffer" from ref_clk, sys_rst active low, XADC on, no extra user clocks).  The MIG's aresetn = !ui_clk_sync_rst registered in ui_clk (also the converter's master reset); address bits 29:0 to the MIG (1 GB); mem_ready = init_calib_complete through am_sync.  In simulation the whole module is
`sim/models/kc705/atg_kc705_mig.v`: an axi_mem (512-bit, 1 MiB, random ready/latency, its
protocol checker) in gclk and mem_ready CALIB_CYCLES after reset.

The board's registers (ws288 p024), at 0x1F000 + 4 * index in the GHCI register window (the JTAG bridge and BAR0 reach them):

| Index | Name | Meaning |
| --- | --- | --- |
| 0 | ID | 0x4B374D43 ("K7MC"). |
| 1 | CTRL | RW, reset 0: [0] holds the MIG in reset (its sys_rst; writing 0 again makes it calibrate again); [21:8] the MIG's ddr3_vio_sync_out ([16:8] dbg_bit, [21:17] dbg_dqs, the byte lane of the per-lane fields below). |
| 2 | STATUS | [0] init_calib_complete (mem_ready), [1] mmcm_locked, [2] ui_clk_sync_rst. |
| 4-7 | ILA_BASIC | ddr3_ila_basic[119:0] (MIG_DEBUG 1, MIG 7 Series 4.2 with Debug on: [0] calibration complete, [3:1] write levelling start/done/error, [6:4] phaser lock, [9:7] DQS found, [15:10] read levelling, [17:16] OCLKDELAY, [21:19] write calibration, [27:22] the init state, [92:29] read data). |
| 8-11 | ILA_RDPATH | ddr3_ila_rdpath[127:0]. |
| 12-24 | ILA_WRPATH | ddr3_ila_wrpath[390:0]. |

The debug ports are in ui_clk and come into gclk bit by bit through am_sync (a snapshot, not coherent across bits; enough for a calibration that has stopped).  The model returns ID and STATUS[0] only.

## 7. Corner cases and errors

- The MIG's Debug option is off in the board's build; for ILA_* set Debug_En ON in atg_kc705_ddr3.prj, regenerate the core and set MIG_DEBUG 1.
- The cores' ports were compared with the generated `_stub.v` files and `sim/lint/xilinx_stubs.v` (Vivado 2026.1, ws288 p024): all match.  The MIG's calibration on the board is not tried yet.
