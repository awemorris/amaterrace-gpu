## 2026-10-24 の決定（handover の後）

ユーザー「では、ZYBOではDCの検証ができたのでもうそれでよしとして、KC705だけをターゲットに変えましょう。」→ GPU の目標は KC705 だけ。p005 は cleared（V1 の目視まで、V2〜V5 は不要）。ZYBO の raster・compute の bitstream は作らない（SU の FPU が 7010 に入らない件は不要になった）。次の着手は p012（KC705: MIG の DDR3、clock、JTAG の bridge、`boards/kc705/atg_kc705_raster`）。注意: SU は NPHYS 8 で約 70.7k LUT（FPU 39k）なので、325T（203,800 LUT）に NPHYS 16 の SU を複数は入らない見込み。KC705 の SU の数・NPHYS・FPU の lane の数は p012〜p015 で合成して決める。

- 2026-10-24 ユーザー（FP16 だけの GPU の話の後）「了解です。そのまま勧めましょう。」→ KC705 の SU は案 A: fp32 は FPU の少ない lane（例: NPHYS 8 の SU に FPU 1〜2 lane、32 lane を順に流す）、fp16 の packed の演算（PACKED）は全 lane。Vulkan の fp32 の正しさは保ち、速さを fp16 に寄せる。案 B（頂点の変換は VF/RX の固定の回路で fp32、SU は fp16 を主に）は合わせて検討。FPU の lane の数は p012〜p015 の合成で決める。
- **2026-10-24 ユーザー「FP32は全laneでいいと思います。」→ 直前の案 A（fp32 は FPU の少ない lane）を改める: KC705 の SU は fp32 の FPU を全 lane に持つ（NPHYS 分）。fp16 の packed（PACKED）も持つ。SU の数・NPHYS は KC705 の合成で決める。**

- 2026-10-24 ユーザー「あとDCはKC705に移植して、HDMI出力を可能にしたいですね。VGAは正直、RTLは残していいけど、もう合成しなくていいです。」→ DC は KC705 に移して HDMI を出す（KC705 の HDMI は ADV7511 の encoder 経由: I2C の設定（`atg_dc_i2c`、今は stub）と並列の画素の data。pin と設定は UG810・board の資料で確かめる、U7）。VGA の RTL（`atg_dc_vga`）は残すが、今後の bitstream では合成しない。
- p007 の続き（2026-10-24 Q1）: RX の fadd・fmul・fdiv の spec を書き、RX・ROP の spec に P3 の決定（sp_tri の edge の配置、15.8 と guard band ±16384 px、Vulkan の近平面、stencil 未実装、STATE の bit、sequencer の待ち）を ACK として記録した（amaterrace-gpu 09fcf49）。残り: `docs/ghci.md` の §8 に RX・ROP の STATE の番号と bit（STATE の番号は include に名前が無く RTL の中の数値: 先に `ghci_regs.vh` に名前を付ける）、再開点 2 は 2026-10-24 Q1 が TB を書いた（amaterrace の branch `p007-raster`、未 merge）: ring は通るが depth が全部 model と違う（[phase007](phase007/phase.md) の末尾）。2 は 2026-10-24 Q1 が直して main に入れた（DRAW_RAW の kick が 1 cycle 早かった、atg_cp_seq の settle、amaterrace 2d5fcf2）。3 も済み（Verilator の raster の PNG）。amaterrace に Makefile と GitHub Actions の CI も足した（[phase007](phase007/phase.md) の末尾）。4 は途中: KC705 の out-of-context の Vivado で WNS −3.153 ns（200 MHz の目標に対し約 122 MHz、ROP の blend が律速、[phase007](phase007/phase.md) の末尾）。残り 4〜5（Verilator の PNG、Vivado は KC705 で、板の script）。
