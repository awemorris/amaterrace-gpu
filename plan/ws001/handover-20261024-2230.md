## 3. 今日の決定（全文は Master の decisions-log）

- 目標の板は **KC705 だけ**（ZYBO は DC の検証で終了）。
- **RTL を一通り揃えるのを優先**: 「今回は合成できればいいことにして、KC705での動作とパイプライン分割はあとにしませんか？全体のRTLをまずは一通り揃えることを優先したいです。」「タイミングの調整はまだ行わないので、KC705 での動作確認は後にします。実装を優先し、次のフェーズへ進んでも OK です。」
- **板の確認と timing は別の Phase**: 「タイミングの調整と KC705 での確認は別なフェーズに分けた方がいいと思います。」→ 新設 [p024](phase024/phase.md)（KC705 の板）と [p025](phase025/phase.md)（200 MHz）。
- **GHCI の仕様**（amaterrace-gpu `docs/ghci.md`、人に見せる体裁に整理済み、実装の状況の記述は削除）:
  - platform（生の MMIO）が本体、PCIe はその mapping（§15）。USB はやらない。
  - host からは register・doorbell・local の窓だけ、他は GPU の DMA。unified と discrete はバッファの確保の場所の違いだけ（§11.3、MEM の capability id 8）。coherence は platform の性質（§11.4）。
  - session の保護は任意（§11.6、PROT の capability id 9、BUFFER_GRANT/REVOKE 0x10106・0x10107）。firmware は未追従（§6 の残件）。
  - 標準 ISA GSI1 を §12 に統合（`docs/gsi1.md` は削除）。CAPS[17]〜[28] と fault kind 8 を追加、CAPS[28] PACKED は新設。
  - `shfl` の sub 4 は `rot`（ユーザー「(b)にしましょう。」）。
- README は人に見せる体裁に整理済み（ユーザーが名前の由来を末尾の Misc に移した）。

## 5. 次の候補（推し順）

1. **p009 の残りを閉じる**: `qd` と helper lane の確認（SU の program）、deadlock の回避の確認、Vulkan に合わない TU の 3 点（trilinear は 2 回に分けて引く、border の色の STATE、compare）。
2. **p018**（firmware の Vulkan の object model と draw/dispatch）と **p010**（compiler の backend、zedBSD `isa/gsi1/`）: RTL が揃ったので、ソフトの側。p010 は interface 表の 4 語目の配置（`docs/ghci.md` §12.10 で「未確定」）を決める。
3. **p006** の見直しと再開（driver）。
4. RTL の残り: SA（延期、ユーザーの決定で SU の後）、`atg_su_rq`（予約）。
5. 板（p024）と timing（p025）はユーザーが始めると言った時。

## 6. 残件・注意

- firmware（`fw/cp/cmd.c`）は GHCI §7.2・§11.6 に未追従: SESSION_OPEN の未知の flag を拒む、frame の中の SESSION_OPEN/CLOSE・GRANT・REVOKE を拒む。
- `atg_cp_seq.v` は 408 行（400 行の上限を超える、前からの超過）→ p016 で分ける。
- `atg_top_shade`・`atg_top_tex` は iverilog で 2〜3 分、`atg_su` は約 25 分（`SIM_TIMEOUT=1700` が要る）。
- 保持の register: subgroup の lane の値は register で持つ（design の distributed RAM と違う）。面積は p025 で測る。
- KC705 の未確認（p024）: HDMI の pin（外部の 2 つの資料が一致しているだけ）、MIG・clock converter の IP の port の名前、ADV7511 の初期化の値。
- Verilator 5.032 の V3Gate の dedup の不具合で、board の top の lint にだけ `-fno-dedup`（`tools/lint.sh`）。
- 未 push（§2）。
