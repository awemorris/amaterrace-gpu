# vk-required-formats.txt: the format features that Vulkan 1.0 requires of
# every implementation, as facts copied from the Vulkan specification
# (Khronos Vulkan-Docs, chapter "Formats", section "Required Format
# Support": the tables of the Sub-Byte, 1-3 Byte, 4 Byte, 10-bit, 16-bit,
# 32-bit, 64-bit/uneven, Depth/Stencil and BCn/ETC2/ASTC formats, the marks
# of Vulkan 1.0 only; later versions' rows and marks left out).  Values
# referenced: Vulkan specification, VkFormat values and the Required Format
# Support tables.  Read by tools/fmtmodel.py (--selftest, and --vectors for
# sim/vec/fmt_required.txt and sim/tb/atg_fmt_tb.v).
#
# Lines: VkFormat value, name, the required features:
#   before '|' (optimalTilingFeatures): S SAMPLED_IMAGE and BLIT_SRC,
#     F SAMPLED_IMAGE_FILTER_LINEAR, C COLOR_ATTACHMENT and BLIT_DST,
#     B COLOR_ATTACHMENT_BLEND, D DEPTH_STENCIL_ATTACHMENT,
#     s STORAGE_IMAGE, a STORAGE_IMAGE_ATOMIC;
#   after '|' (bufferFeatures): V VERTEX_BUFFER, u UNIFORM_TEXEL_BUFFER,
#     t STORAGE_TEXEL_BUFFER, x STORAGE_TEXEL_BUFFER_ATOMIC.
# The capital letters are those of the GPU's fixed-function units, which
# the FMT capability reports; the lowercase ones a driver provides through
# shader programs (they are listed, not checked against the hardware).
# "oneof LETTERS A B": at least one of the formats has the features.
# "family LETTERS A-B / C-D / ...": every format of at least one of the
# ranges has them (the compressed formats).
